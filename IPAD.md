# RawPad: LightCraft for iPad

RawPad is a personal, native iPadOS port of [LightCraft](https://github.com/storytold/lightcraft).
It runs the same Rust engine and the same egui UI, drawn with Metal and adjusted for touch. It is
installed on one iPad with SideStore and a free Apple ID. It is based on LightCraft by the ArtCraft
team and is not an ArtCraft product.

## For agents: start here, every session

Sessions have no memory, so the files below are the memory. Read them in this order:

1. `HANDOFF.md`: where the previous session stopped and the very next step.
2. `FEEDBACK.md`: Ivan's notes from testing on the iPad. These come first.
3. `PROGRESS.md`: phases, status, next tasks, `## Needs Ivan`.
4. `DECISIONS.md`: dated decisions. Don't re-decide them without a new entry.
5. `SETUP.md`: install, refresh and update steps for Ivan.
6. `UPSTREAM.md`: last upstream merge and local patches to upstream files.

The kickoff brief, with every decision from 2026-10-18, is `lightcraft-ipad-brief.md` in the
claude.ai Project (not in this repo).

## Layout

| Path | What |
|---|---|
| `apps/rawpad-ios/` | The iOS host crate (binary `rawpad`). winit (UIKit) + egui-winit + egui-wgpu (Metal) hosting `lightcraft-ui-egui`. Compiles to a stub on other targets. |
| `ios/Info.plist` | App bundle metadata (bundle ID `io.github.ivanmagpelmeni.rawpad`, iPad only, all orientations, multitasking, Files sharing). |
| `ios/build.sh` | `sim` builds an ad-hoc-signed `.app` for the simulator. `device` builds an unsigned `.ipa`. |
| `ios/sim_test.py`, `ios/sim_tour.jsonl` | Drive the app in the iPad simulator over the control channel and take real screenshots (`xcrun simctl io`). |
| `ios/update_source.py`, `sidestore/source.json` | The SideStore/AltStore source, updated by CI on each release. |
| `ios/icon/` | The app icon (original, generated by `make_icon.py`). |
| `.github/workflows/ipad.yml` | CI: build, simulator test and screenshots, then a release with the `.ipa` and the source update. |

## Rules (in addition to upstream's CLAUDE.md / AGENTS.md)

- **Keep iPad code in our own files.** iOS code goes in `apps/rawpad-ios` and `ios/`. Patch
  upstream crates only when unavoidable, behind `cfg(target_os = "ios")`, and log every patch in
  `UPSTREAM.md`.
- **Never crash.** Upstream's never-crash rules apply in full. If FFI ever needs `unsafe`, it goes
  in a small module of our crate with `// SAFETY:` comments and a `DECISIONS.md` entry.
  `main.rs` currently has `#![forbid(unsafe_code)]`.
- **One app target and a stable bundle ID.** No extensions: the free account has a weekly App ID
  limit.
- **Release only green builds.** CI publishes a release only when the simulator test passes.
  Never leave main red; revert if needed.
- **Keep secrets and personal data out.** The repo is public, so no secrets and no personal data,
  in `FEEDBACK.md` too. Never ask for Ivan's Apple ID or passwords.
- **Look before claiming.** Check CI with the GitHub tools and look at the screenshots before
  saying something works.
- **This sandbox can't compile Rust.** Claude sessions here can't reach crates.io, so CI is the
  compiler. Push small commits and read the CI logs. `rustfmt` works offline: run
  `rustfmt --edition 2024 apps/rawpad-ios/src/main.rs` before committing.
- **Commits:** prefix with the phase, e.g. `P2: …`, one task per commit, ending with the
  attribution lines.
